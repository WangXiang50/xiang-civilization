# 军队

> 一个天生不擅长服从的民族，怎么建军队。

[← 目录](../index.md)

## 设定要点

- 军队是文明最大的制度 exception。不把"服从"塑造成人格美德，而是**预先授权部分 decision rights**。
- **Design Mode / Execution Mode**：设计阶段必须质疑；合法决策一旦完成——"模型关闭，任务开始"。
- 军官的核心是愿意在信息不足、时间有限、后果严重时承担 decision liability。复盘极其凶残。
- 军人、警察去博物馆免票（历史 reciprocity，不是职业等级更高）。

## 展开

### 军队长什么样

会，而且我觉得这会是向往文明最有意思的 institutional exception 之一：他们最后不得不承认一件自己文化上很不舒服、但现实上绕不过去的事——

军队确实不能在炮弹飞过来的时候开 brainstorm meeting。

所以军队会成为整个文明里少数明确承认“局部服从具有正价值”的机构。但它不会试图把整个军人训练成服从型人格，而会把服从设计成一种窄范围、强边界、可撤销的专业协议。

最核心的原则大概是：

入伍不是放弃agency，而是预先授权：在特定条件下，由特定指挥链暂时使用我的部分decision rights。

这非常向往文明。

普通社会是“权力跟着任务走”；军队则把它推到极致：command authority跟着mission走。

平时一个士兵完全可以问：

“这个训练为什么这样设计？”

“这个装备为什么选这个？”

“这个流程第三步是不是多余？”

甚至军队非常鼓励这种东西，因为战争前能发现bug当然比战争中发现好。

但是进入mission state以后：

“撤到B点。”

不能回答：

“我觉得A点其实也有一定战略价值，我们能不能先讨论一下？”

不行。走。 😂⁠

他们会非常明确地区分两个状态：

Design Mode 和 Execution Mode。

Design Mode里，质疑是职责。

Execution Mode里，在合法命令和既定授权范围内，执行是职责。

所以军队最重要的训练之一甚至不是“学会服从”，而是：

学会什么时候停止重新计算。

这对向往人可能特别难。😂⁠

而且他们的军队一定会非常强调commander's intent，而不是无限细节命令。

因为你不可能真的把一群高agency的人训练成机器人，而且现代战争本身也不适合所有信息都等总部决定。

上级不会只说：

“你必须沿这条路走。”

而会说：

“任务目标是保证这个港口在18小时内仍然可以使用；红线是不得攻击某区域；如果通信中断，你拥有这些decision rights。”

然后下面的人自己解决。

这会让他们特别擅长mission command / decentralized execution。

也就是：

战略目的高度统一。

局部执行高度自治。

所以一个基层军官可能拥有比很多文明基层军官大得多的decision space。

但是代价也很明显：这个军官必须非常清楚什么时候自己的判断可以override默认方案，什么时候不可以。

他们最怕的不是“士兵没有思想”。

而是：

每个人都觉得自己的local model比整个system更聪明。

所以军事教育里一定会反复讲：

“你拥有局部信息，不等于你拥有全局信息。”

这句话对向往文明的人可能是一剂特别重要的解毒剂。

他们也会设计非常硬的服从边界。

因为既然社会允许军队获得异常强的command authority，那它就必须被装进一个非常窄的盒子。

什么人可以下什么命令。

在什么mission state下有效。

什么时候自动失效。

什么命令必须拒绝。

什么命令可以请求确认。

什么命令即使不同意也必须执行。

全部会被设计得极其清楚。

所以他们不会接受：

“军人的天职就是服从。”

这句话太宽。

他们会改成：

“军人的职责是在合法授权的任务结构中可靠执行。”

差别巨大。

违法命令不是“先执行再说”。

私人命令不属于command authority。

任务结束以后，上级不能继续把战时command relationship带回私人生活。

将军不能因为是将军就在餐厅里比别人更有decision right。

出了基地，他就是一个人。

而且他们的军队会有极其凶残的after-action review。

战斗的时候：

“执行。”

回来以后：

“现在开始骂。”

😂⁠

基层士兵可以说：

“第三阶段那个命令是错的。”

“为什么？”

“因为这里。”

拿数据。

指挥官如果真的错：

“收到。”

进入系统更新。

而不是：

“你怎么敢质疑长官？”

甚至一个军官如果每次复盘都用rank压住下面的人，会严重影响晋升。

因为向往文明会认为：

战时服从给了你巨大的temporary power，所以战后你承担巨大的explanation liability。

这很漂亮。

执行时，我暂时把decision right交给你。
复盘时，你必须告诉我你拿它做了什么。

所以他们的军官选拔也会非常不一样。

最差的候选人之一就是：

特别喜欢别人服从自己的人。

😂⁠

面试：

“你为什么想当军官？”

“我喜欢领导别人。”

扣分。

“我觉得军队需要纪律，下级应该服从——”

继续扣。

真正好的答案可能更接近：

“我愿意在信息不完整、时间有限、后果严重的时候承担decision liability。”

这才是command。

因为command在向往文明不是prestige。

是：

最后必须有人按按钮，而且按错了算你的。

所以高级军官的prestige可能非常高，但心理负担也极重。

还有一个很有意思的结果：他们的普通士兵可能不是特别适合传统的“站得整整齐齐、喊口号、无意义重复队列”。

向往士兵：

“这个齐步走和combat effectiveness的相关性是多少？”

教官：

“……”

😂⁠

所以很多传统军队用来制造服从感和集体身份的仪式，在他们那里会少很多。

有些仍然保留，因为coordination、身体控制、仪式和单位凝聚力确实有utility。

但如果理由只是：

“军队一直这样。”

不够。

他们的训练会更加集中于：

极端压力下执行协议、通信中断后的自治、快速切换command state、识别合法命令、团队互信、武器与系统熟练度、信息不完整决策、以及在自己不同意的时候仍然执行已经合法确定的方案。

最后这一项可能特别难。

因为真正的纪律不是：

“我同意，所以我做。”

而是：

“我已经表达了反对；decision已经合法做出；现在轮到我执行。”

这会被认为是一种很高级的professional capacity。

但这个军队也会有明显弱点。

比如和平时期特别容易吵。😂⁠

军事采购：

陆军：“这个系统不行。”

海军：“你的模型错了。”

AI：“目前两方使用了不同的objective function。”

国会：“已经开了六个小时了。”

军方：“这是Design Mode。”

😂⁠

而一旦真的进入战争，反而可能突然非常安静。

因为所有人都知道：

Search结束了。现在是Execution。

这甚至会成为一种非常强的文化仪式。

重大行动开始前，指挥官最后一次问：

“还有没有未提出的关键异议？”

大家说完。

记录。

决策。

然后一句：

“模型关闭，任务开始。”

从这一刻起，不再继续为已经决定的东西消耗compute。

所以向往文明的军队不会解决“向往人不擅长服从”这个问题。

它会换一个问题：

如何让一个不崇拜服从的社会，仍然能够在必要的时候产生极高可靠性的服从？

答案不是把人训练成听话。

而是让他们非常清楚：

我把什么decision right交给了谁、为什么交、什么时候必须执行、什么时候必须拒绝，以及什么时候这个授权结束。

这其实比“服从是一种美德”更符合整个文明。

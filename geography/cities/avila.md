# 阿维拉（Avila）

> 阳光、山海、biotech、电影：这个世界的 LA

## 设定要点

- biotech、longevity、电影、娱乐、美容医美、生活方式产业。
- 占星在这里尤其火："你这个 sample size 是多少？""闭嘴。"

## 城市性格

这个我觉得你会非常喜欢。

城市非常铺开。

山。

海。

漂亮天气。

大量低层住宅。

biotech cluster。

电影工业。

设计。

longevity。

pet biotech。

高端医疗。

健身文化。

娱乐业。

阿维拉人白天可能在做神经科学，晚上去看stand-up，周末去海边，偶尔接一个完全不相关的side gig。

这个城市特别允许：

一个人同时活好几种生活。

所以全国其他地方觉得阿维拉人“不严肃”。

塞拉人尤其看不起：

“他们约上午十点的meeting，十点零七还在停车。”

阿维拉人反击：

“至少我们有太阳。”

😂⁠

它还有非常发达的美容、健身、anti-aging industry。

全国最好的整形医生、皮肤科、longevity clinic都在这里。

所以这里的人平均确实很好看。

但也因此催生大量荒谬产业。

“细胞年轻化spa”。

“神经美容”。

“AI facial longevity analysis”。

监管局常年驻扎阿维拉。

全国监管人员私下称它：

“bullshit 的自然保护区，也是新产业的孵化器。”

因为十个荒谬东西里面真的会冒出一个未来产业。

这就是阿维拉最烦人也最有价值的地方。

## 吃什么、喝什么

阿维拉：全国最会把“健康”做得真的很好吃的地方。

因为阳光、健身、电影、biotech、美容、longevity文化都在这里，所以阿维拉菜会大量使用：

鱼、虾、牛油果、柑橘、香草、番茄、坚果、橄榄油、豆类、新鲜水果、发酵食品。

早餐非常阿维拉：

烤面包 + 蛋 + 牛油果 + 酸味绿叶菜 + 冰咖啡。

全国其他城市：

“你们又在吃叶子。”

阿维拉：

“很好吃啊。”

而且是真的很好吃。😂⁠

这里是全国 raw / lightly cooked seafood 最强的地方之一。

柑橘腌鱼。

海胆。

生蚝。

炭烤虾。

各种很轻的鱼。

但阿维拉也有一个隐藏传统：

非常好的 taco-like street food。

因为南方和跨洋移民影响，晚上大家穿得漂漂亮亮，从高级酒吧出来以后蹲在路边吃烤肉卷。

这在阿维拉完全不矛盾。

白天：

“我最近在控制 inflammation。”

凌晨一点：

“再加一个。”

饮料就是我们已经给这个文明定出来的那一整套：冰美式、无糖茶、气泡水、柑橘水，以及大量 botanical spirits。

全国最好的 gin-like 酒很多就在阿维拉附近。

经典喝法：

冰 + 酒 + 一点水 + 柠檬皮。

阿维拉人会嫌甜鸡尾酒：

“为什么我要喝液体蛋糕？”

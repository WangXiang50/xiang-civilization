# 向往文明 · Xiang Civilization

> 它既不相信世界可以被完全规划，又极度热衷于建立自己的规则。

这是一个玩了很久的思想实验：**如果一个人的人格不是一个人，而是一整个文明，它会长什么样？**

起点只是一个 prompt。后来一路追问下去：这个国家的人吃什么、怎么谈恋爱、怎么离婚、谁会被歧视、税怎么收、军队怎么建、博物馆里放什么、老人爱干什么……最后长出了一个有地理、历史、制度、市场、节日、俚语、失败产业和历史创伤的完整社会。

这里是它的整理版 wiki。

## 一句话版本

**有地板，没有天花板。**

社会保证你不会摔穿基本生活，但不限制别人能赢到多高。成年人拥有自己人生的最终选择权，制度负责保护选择的条件，不负责审核选择的内容。

不崇尚吃苦，崇尚成事。辛苦是成本，不是勋章。

## 尝几口

- 离婚非常容易，所以离婚律师这个职业消失了。真正打得头破血流的是抚养权，于是出现了小猫律师、小狗律师，还有很贵的**鹦鹉律师**。
- 丈母娘不看你是公务员还是做游戏的，只看你有没有**穿越周期的变现能力**。
- LV、香奈儿、爱马仕开进来，没人买，又关了。最大的炫富是太空旅行："我这个包八十万。""嗯。""我刚从太空回来。""你坐这儿，讲。"
- 薯片可以有肉味，但不能把肉味香精放到肉上。有人想用进口化学料包开螺蛳粉店，被罚了。
- 博物馆里有一面**普通人墙**，所有人都可以抽签展一天。后来有人在上面展示自己做的吃的，有人吃过敏了，从此只许展示文艺作品。
- 有一家无包装商店火过一阵，后来倒了。经典抱怨："我买个胡椒为什么生成了一个 workflow？"
- 骂人话里仅次于"大傻逼"的是"**二极管脑子**"：只会认为一件事行或不行，不承认中间态。
- 军人进入任务前说"**模型关闭**"。设计阶段必须质疑，执行阶段不再重开问题。
- 历史上最大的灾难叫**大开门运动**："任何人都无权替另一个人关闭可能性。"最后七港桥塌了。刻在议会大厅里的那句话是："有些门之所以关着，是因为门后没有地板。"
- 这不是乌托邦。有穷人，有蠢人，有痛苦的人；有人活得最累，有人活得最难受。它只是把规则写清楚了。

## 想自己玩一个

最初的 prompt 是这样的：

> 假设我的人格不是一个人，而是一整个文明。
> 根据你对我的了解，设计这个文明的地理环境、政治制度、婚恋制度、审美、宗教、商业模式、教育方式、最强产业和最大社会矛盾。
> 再告诉我：这个文明会在哪个阶段达到巅峰，又会因为什么衰落。
> 请像一个严肃历史学家在研究一个真实存在过的文明，不要写成性格测试。

然后不停地问"那他们……呢？"，或者直接立法："这个文明**不会**有彩礼。"好玩的部分是第二种。

想接着玩向往文明的话，把[底层三观](principles/core-values.md)和[总盘点](overview.md)贴进一个新的对话，从任何一个还没写的角落继续，比如普通人运动的完整历史、某座城市的一天、或者一场开放麦。

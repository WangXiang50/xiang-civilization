# 战争史

> 它不是和平主义文明，它只是对战争的 utility function 极其冷酷。

[← 目录](../index.md)

## 设定要点

- **港口战争时代**：早期城邦之间小规模争夺港口和航道。古话："不要烧掉你明年可能使用的港口。"
- **十二港战争**：第一次大陆战争，大陆帝国逐个控制外围港口。第一次总体战，开局打得很难看（"敌军距首都四十里，审查院要求补充第三版成本收益分析"）。第三年建立五人战争委员会；打到对方无法封锁海岸就签约撤军，只要求航道永久开放。
- **南方干预战争**：第二海洋时代鼎盛期，预计 18 个月，打了 17 年——一个极擅长识别 sunk cost 的文明第一次在国家尺度掉进 sunk-cost trap。反战小说《最后一个指标》。
- **最后一次战争**：衰落期，新兴大陆强国袭击外围港口；议会四天授权、几个月摧毁对方远洋能力；"消除未来威胁"被否决，因为"那没有 stopping condition"。舰队回港。
- 最神圣的领土不是土地，是出口。

## 展开

### 这个文明发生过战争吗

发生过。而且如果把这个文明真的按历史逻辑推演下去，它不可能是一个长期和平文明。

但它的战争史会很有特点：很少为了荣耀发动战争，却会为了“出口不能被封死”打得极狠。

我会把它的军事史分成四个时代。

早期的“港口战争”规模很小。向往文明最初并不是统一国家，而是一串沿海城邦。它们彼此争港口、航道、岛屿和贸易节点，战争更像商业竞争的暴力延伸。今天结盟，五年后翻脸，再过十年重新贸易，非常正常。

所以他们很早就不把“敌国”理解成永久身份。

古代有一句很有名的话：

“不要烧掉你明年可能使用的港口。”

这使早期战争相对克制。他们更喜欢夺取节点，而不是屠城；更愿意迫使对方开放航道，而不是占领大片土地。因为土地本身不是这个文明最重要的资产，network connectivity 才是。

真正改变这个文明的是第一次大陆战争。

大陆深处崛起了一个高度中央集权的帝国。它和向往文明几乎是制度上的镜像：统一法律、统一宗教、统一货币、统一行政体系，动员能力极强。

最初向往各城邦没有把它当回事。

大家分别计算自己的利益。

有的认为可以贸易。

有的保持中立。

有的觉得大陆帝国离自己还远。

有的甚至向帝国出售船只。

这后来成为向往文明历史教育中最著名的失败案例：局部理性制造了系统性灾难。

大陆帝国逐个控制外围港口，最后开始要求核心城邦接受驻军和贸易审查。

这时候他们才发现一个非常严重的问题：

每一个城市 individually 做出的选择都很合理，但整个 network 正在被关闭。

于是爆发了后来所谓的**“十二港战争”**。

这是他们第一次真正意义上的总体战争。

而且打得非常难看。

因为向往文明一开始根本不会打总体战。各城市争论预算、兵力、指挥权，商人不愿意停贸易，议会不断要求重新评估战争目标。

大陆帝国军队已经推进，他们还在开会。

后世喜剧对此有一个著名段子：

“敌军距离首都四十里。
审查院要求补充第三版成本收益分析。”

但战争进行到第三年以后，整个文明发生了一次极其重要的制度突变。

他们第一次建立了临时战争政府。

平时高度分散的权力被暂时集中到一个五人战争委员会，而且出现了一条后来极具争议的宪法原则：

在明确的生存性威胁下，可以暂时牺牲 option value，以保存未来拥有 option 的能力。

这几乎成为他们政治哲学里的经典悖论：

为了保留选择，有时候必须暂时停止选择。

十二港战争最后没有以征服大陆结束。

他们打到大陆帝国无法继续封锁海岸，然后签约。

没有占领对方首都。

没有要求改造对方制度。

只要求几件非常向往文明的东西：

航道永久开放；

港口不得驻扎足以封锁航运的军队；

贸易自由；

双方交换俘虏。

然后撤军。

因为议会认为继续推进的 marginal return 已经转负。

将军要求乘胜追击，被拒绝。

这件事后来被视为他们军事文化真正成熟的标志：

战争不是 narrative。战争是有 stopping rule 的 state intervention。

但几百年后，他们还是犯了一次完全相反的错误。

第二海洋时代鼎盛期，向往文明已经富得惊人，科技领先，海军强大，于是开始相信自己可以用有限军事力量“修复”外围地区的不稳定。

这就是历史上臭名昭著的南方干预战争。

起初理由非常漂亮：保护贸易、阻止屠杀、稳定航道、扶持一个更可靠的当地政府。

预计十八个月结束。

最后打了十七年。

这是他们第一次发现：

一个项目即使最初有 stopping rule，也可以通过不断修改 stopping rule 逃避 closure。

每次快退出的时候，政府都会说：

再稳定一个省。

再训练当地军队。

再等一次选举。

再确保撤军以后不会重新恶化。

一个极其擅长识别 sunk cost 的文明，第一次在国家尺度上掉进了 sunk-cost trap。

南方战争成为他们的越南战争式创伤。

文学、电影和政治文化都被它改变。

最著名的反战小说不是描写战场，而是一本叫《最后一个指标》的小说：主人公是战争部的统计官，每一年都被要求设计一个新的指标，证明战争“正在接近结束”。

最后他发现自己的真正工作不是测量现实。

而是不断重新定义成功，使一个无法结束的项目看起来仍值得继续。

这本书后来甚至进入公共管理教材。

而这个文明历史上最后一次大规模战争，反而非常短。

衰落期，一个新兴大陆强国判断向往文明已经官僚化、内部争论严重，不敢承担战争成本，于是袭击了几个外围港口。

它判断对了一半。

这个文明确实已经非常厌恶战争。

但对方碰到了它政治文化里最危险的 trigger：

试图关闭出口。

几百年的党争突然失去意义。

议会用了四天授权战争。

舰队用了几个月摧毁对方的远洋能力。

然后出现了一个非常典型的场景。

军方提交继续进攻大陆本土的计划。

审查院问：

“我们的战争目标是什么？”

军方说：

“消除未来威胁。”

审查院回答：

“那没有 stopping condition。”

计划被否决。

舰队回港。

所以后世军事史家对这个文明有一句非常准确的评价：

它不是和平主义文明。它只是对战争的 utility function 极其冷酷。

侮辱它，未必开战。

意识形态不同，不开战。

别国生活方式让它看不顺眼，也不开战。

甚至失去一些土地，都可能先算账。

但如果有人试图让它只剩下一条路——封港、垄断航道、禁止退出、摧毁它产生 alternative branches 的能力——战争意愿会突然陡升。

因为对这个文明而言，自由最深层的定义从来不是“我想做什么就做什么”。

而是：

无论现在这条路发生什么，我仍然拥有下一条路。

因此它最神圣的领土其实不是土地。

是出口。

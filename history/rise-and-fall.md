# 巅峰与衰落

> 它靠 side doors 建立帝国，最后却死于所有 side doors 都需要提前预约。

[← 目录](../index.md)

## 设定要点

- **最大的社会矛盾**：探索文明最终会遇到 closure crisis。
- **巅峰：第二海洋时代。**第一海洋时代解决"怎样拥有更多道路"，第二海洋时代解决"怎样知道哪条道路值得走完"——极高 optionality + 极强 closure。
- **衰落**：不是战争，不是贫穷，而是成功把整个文明变成 maintenance system。每一条规则都合理，option generation rate 却在下降；某一天委员会说"这不属于任何现有类别"，项目就没有发生。

## 展开

### 最大的社会矛盾：closure crisis

向往文明最深刻的矛盾，不是贫富，也不是阶级。

而是：

一个极其擅长产生可能性的文明，怎样结束一件事情？

早期，这种文化具有巨大优势。

别人只有一条贸易路线，它有七条。

别人培养一种人才，它可以快速跨领域。

别人押注一个产业，它同时做几十个小实验。

一个失败，迅速退出。

另一个成功，立即扩大。

这是它崛起的秘密。

可是到了鼎盛期以后，问题开始出现。

港口越来越多。

学院越来越多。

项目越来越多。

合作越来越多。

每一个系统都能提出新的 scientifically valid next question。

每一个成功项目都会生成三个值得继续的项目。

没有人愿意做愚蠢的重复劳动，但文明运行偏偏需要大量 maintenance、administration、closure 和 boring execution。

于是这个社会产生一个非常特殊的职业阶层：

终结者。

他们不负责提出新想法。

他们负责让船真正抵港，让论文真正出版，让工程真正交付，让战争真正结束，让项目真正关账。

鼎盛时期，终结者的社会地位甚至会超过哲学家。

因为整个文明最终发现：

idea 已经不是稀缺资源。Closure 才是。

### 巅峰：第二海洋时代

向往文明不会在扩张最快的时候达到巅峰。

真正的黄金时代发生在它学会约束自己的时候。

历史学家称之为第二海洋时代。

第一海洋时代解决的是：

我们怎样拥有更多道路？

第二海洋时代解决的是：

我们怎样知道哪条道路值得真正走完？

这时文明形成了一套成熟的制度组合：

探索阶段允许极高自由度；

证据门槛出现以后迅速集中资源；

低价值项目自动终止；

高价值项目必须拥有明确 closure owner；

任何组织都必须区分 exploration budget 和 execution budget；

任何宏大计划都必须留下 exit right；

任何已经进入 execution 的项目，则不能无限重新开放问题。

这大概是这个文明最强的时期。

因为它第一次同时拥有了两种此前互相冲突的能力：

极高 optionality + 极强 closure。

这时它会成为世界上最强的科学、医学、贸易和技术文明之一。

不是因为人口最多。

而是因为它把每单位人的认知资本利用到了惊人的程度。

### 衰落：成功变成了 maintenance system

真正摧毁它的不会是一次外敌入侵。

更可能是一场缓慢的制度硬化。

第二海洋时代积累了大量成功组织。成功组织变成机构，机构产生流程，流程产生管理者，管理者为了降低风险开始要求标准化。

最初这些标准化完全合理。

然后一点点增加。

港口需要许可证。

学院需要 accreditation。

实验需要审批。

公司需要 compliance。

职业需要 credential。

曾经为了减少 friction 而创造的制度，开始自己制造 friction。

最危险的是：每一个单独规则看起来都合理。

没有哪一天发生政变。

没有暴君宣布自由结束。

只是整个文明的option generation rate开始下降。

年轻人第一次发现，他们进入一个新领域之前，需要先证明自己已经在那个领域工作过。

小公司发现试一次新东西的 transaction cost 已经高于实验本身。

学院开始奖励维护已有范式的人，因为他们“更可靠”。

最优秀的人仍然聪明。

甚至可能比黄金时代的人更聪明。

但他们开始把越来越多的认知资源用于维护系统，而不是改变 state。

这才是向往文明真正的衰亡。

不是战争。

不是贫穷。

甚至不是 decadence。

而是某一天，一个年轻学者提出一个非常奇怪但可能重要的问题，委员会看了看表格，说：

“这不属于任何现有类别。”

于是项目没有发生。

一千年前，这个文明正是因为会对这种东西说一句——

“先跑一下。”

——才开始崛起。

它的历史因此具有一种相当冷酷的对称性：

它靠 side doors 建立帝国，最后却死于所有 side doors 都需要提前预约。
